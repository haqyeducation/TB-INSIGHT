# TB-INSIGHT synthetic demo frontend

Frontend React/Vite untuk prototype synthetic Surabaya. Banner synthetic pada aplikasi tidak boleh dihapus.

```powershell
npm ci
npm run dev
```

Vite meneruskan request `/api` ke backend lokal pada port 8000. Gunakan `VITE_API_BASE_URL` hanya jika backend berada pada alamat lain.
